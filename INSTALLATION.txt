期刊全文下载器 · Windows 安装版

安装到当前用户，无需管理员权限。后续更新请覆盖安装到原来的位置。
开始菜单提供程序入口，也可选择创建桌面快捷方式。

首次从 v1.5.0 或更早的便携版迁移，请先关闭旧程序，再运行此安装包。
以后请通过开始菜单或新快捷方式启动，旧的便携 EXE 不会自动删除。
旧版内部更新不能自动切换为安装版，需要手动安装这一次。

现有论文、保存位置、普通设置及本机加密记忆的 API Key 会保留。
安装和卸载均不删除论文文件夹或本机应用数据。
安装文件不能替代学校订阅权限，图文 PDF 仍是依据 XML 合成的阅读版。

更新时先等待下载/PDF任务结束，再点击右上角向上箭头。
程序会下载并校验安装包，然后关闭当前窗口、打开安装向导。
只有启动新版后才确认更新完成；如取消了安装，可再次运行安装包。
手动安装时如果提示程序仍在运行，请先安全停止任务并关闭程序。
安装器不会强行结束下载任务。

更新安装日志：%LOCALAPPDATA%\JournalXMLDownloader\updates\版本号\setup.log
程序源码与正式安装包：https://github.com/yaluncoco/journal-downloader
